# Contributing

## Pull requests

This project is not currently accepting external pull requests. Pull request
creation is restricted to repository collaborators. Reproducible bug reports
are welcome through GitHub issues.

## AI-assisted contributions

We do not accept unsolicited batches of AI-generated issues or PRs with minimal
human review. Contributors must personally reproduce reported problems,
understand and review their changes, run relevant tests, and disclose AI
assistance. Submissions that shift this work onto maintainers may be closed
without further review.

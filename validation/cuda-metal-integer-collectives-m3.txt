Distributed integer tree statistics — Apple M3, 2026-11-04 local
===============================================================
Scope: scalar/vector roots, histogram caches and vector value-leaf integer
collectives; direct production-updater integration. The learner-wide guard stays.

Source authority:
- tree/updater_gpu_hist.cu::InitRoot: local GPU integer sum, host integer
  GlobalSum, then host dequantization.
- tree/updater_gpu_hist.cuh::InitRoot: per-target GPU integer GlobalSum.
- tree/gpu_hist/histogram.cu::AllReduceHist: GPU integer cache reduction before
  histogram subtraction.
- tree/updater_gpu_hist.cuh::ExpandTreeLeaf: GPU integer leaf/target reduction
  after local pages and before GPU weight calculation / host tree publication.
- Existing independent CUDA-derived quantizer, sampling and float-replay oracle
  in tests/cuda_gradient_reference.h. CPU predictions are a secondary check for
  unsampled finite-bin fixtures where the algorithms agree.

Implementation:
- Explicit SumRoot selects host scalar or Metal vector integer reductions.
  Local Sum remains local and global reduction does not mutate per-row state.
- A small GPU materialization kernel converts completed integer pairs using
  their original per-target scales. Host scalar roots use ldexp after GlobalSum.
- Histogram synchronization reduces the authoritative contiguous integer cache
  range, then refreshes its binary64 view on GPU. Integer subtraction, cache
  growth and integer root sums retain unrounded state.
- Leaf sums reduce all leaves/targets on GPU after local pages, then materialize
  and call existing GPU weight kernels with original value-gradient scales.
- Hist/approx scalar roots, vector roots and value-leaf fitting call these APIs.
  Removed obsolete internal histogram/leaf guards; kept the learner entry guard.
- Shared GradientContainer::HasValueGrad now distinguishes absent (0,0) from
  supplied empty (0,targets) gradients by target dimension. An empty-rank
  production test previously reached SetLeaves with split width 1 and value
  width 3. The CPU/Metal path now prepares value scales and fits leaves on every
  rank. Two matching CUDA updater checks use target dimension as well; their
  NVIDIA compilation/execution is unverified.

Focused development findings:
- Early compile failures were test syntax/type errors. Runtime shader compilation
  then found the new materializer before its helper declaration; moved it after
  xgb_scaled_integer.
- A native SIGABRT came from std::fill with iterators from separate temporary
  Span objects in test setup. An instrumented terminate backtrace localized it;
  storing one span fixed the invalid iterator pair. The attempted LLDB session
  remained stopped at launch and was explicitly ended before instrumentation.
- A residency assertion caught the fixture reading a newly allocated GPU replay
  matrix to initialize it on host. Initialize host inputs before uploading;
  the zero-readback assertion remains unchanged around the tested operations.
- Updater-test compilation/serialization needed a const host tree view and an
  initialized JSON Object. The subsequent empty reduced-gradient failure was
  the production presence bug described above, fixed in shared code.
- Focused v10 passed primitives plus all updater cases. v11 added the cross-rank
  cancellation fixture and passed. No reference tolerances were widened.
- The first public empty-gradient test inferred its width from upstream's empty
  prediction (0,0). It now supplies known (0,3) value gradients explicitly; the
  empty prediction-shape behavior itself was not changed. Public v2 passes both
  CPU and Metal variants.

Limits:
- Direct native updater integration bypasses the retained learner guard. Full
  learner/objective/metric/booster integration and external-memory distributed
  training remain to be validated or implemented.
- Host TCP transports shared Metal buffers. Local workers share this Mac; no
  cross-machine, federated, asynchronous-stream or NVIDIA execution validation.
- Existing sample-mean mixed-weight/empty prediction shape edge cases require
  their own source audit; this change does not claim to resolve them.
- No benchmark or performance claim; full CUDA parity remains incomplete.

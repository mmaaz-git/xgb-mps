Issues caught during development:
  Metal does not support 64-bit SIMD broadcast directly: broadcast both 32-bit
  halves, preserving the full integer carry.
  Subnormal categorical weights initially compared as zero using native floats:
  fixed with IEEE-preserving comparisons, retaining exact expectations.
  The initial full-tree oracle expected unscaled base_weights at terminal children;
  RegTree stores eta-scaled weights there. Corrected the oracle's serialization
  interpretation; production arithmetic was unchanged.

Limits / remaining work:
  Vector-leaf scans and child statistics still use the legacy binary64 path.
  Feature winner reduction, constraint/interaction metadata and scalar final
  weight application remain host operations. CUDA sketch/column RNG alignment
  and other ledger gaps are unfinished. Extreme nonfinite gain/host expansion
  behavior is not resolved. Explicit separately rounded binary64 gain arithmetic
  and default IEEE comparison behavior are source-derived models; NVCC contraction
  and CUDA build/hardware variation still require actual NVIDIA comparisons.
  These local exact tests do not establish full CUDA parity.

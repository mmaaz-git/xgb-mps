Behavior:
- Per-tree GPU integer gradients and per-target scales now have explicit shared
  ownership, independent of a histogram builder's staging buffers.
- Uniform: quantize ORIGINAL gradients, consume seed, mask integers using Philox.
  The original quantizer scale survives rejected outliers. Histogram builders
  retain the state; no float round-trip/requantization or pointer registry.
- All hist/approx roots (scalar/vector/dense/missing/sparse/external/zero-bin)
  sum the same integer pairs as histograms and convert only after summation.
- Uniform replay applies the identical mask to raw position bookkeeping and
  reduced value gradients, including different target counts/strides.
- CUDA modern branch: uint32(seed), Philox4x64-10, discard(row), FP32 conversion
  before division by 2^64, draw <= probability. Rate < 1 consumes a seed even
  for empty input; rate 1 consumes none. Legacy Thrust stream is not covered.
- Fixed logical column extents: TensorView::Values() can include later columns'
  backing storage. Quantization/histogram inputs now use the logical row count.
- Added quantized_gradient_sum_dispatches and cuda_uniform_sampling_dispatches;
  both are zero in CPU-only builds. All native binaries rebuilt for the ABI.

Initial failures exposed/fixed the multi-target extent bug. Native fixture
constructor types and a resumed-oracle round offset were corrected separately.
No tolerance was widened and no new performance benchmark was run.

Remaining: gradient-based sampling still uses the CPU-oriented float norm/prefix/
RNG/rescale path, then quantizes and shares that result. It must be replaced by
CUDA's original-quantized norm, integer-prefix, and rescale/requantize algorithm.
Leaf sums, split scans/child statistics, column/ranking RNG, sketches and the other
coverage-ledger gaps remain. Full CUDA parity and NVIDIA execution validation are
NOT complete.

  CUDA common/quantile.cuh:93-108 initializes device column pointers, snapshots
  feature types and uses device any_of to determine categorical presence.
  MetalCudaSketch now clears its initial resident column-pointer payload with
  a GPU blit, including the single pointer for zero columns. Implicit numerical
  types are also cleared on GPU. Supplied types feed an owned GPU snapshot;
  native inputs bind directly, including unaligned byte subspans. Host metadata
  inputs retain the existing borrowed-memory/staging fallback contract.
  xgb_cs_has_categories performs a SIMD any-reduction followed by atomic OR.
  Its GPU-cleared flag is read only after completion, as host scheduling metadata.
  CPU std::find and CPU zero-vector construction/upload were removed.
  Temporary pointer arrays remain allocated and populated by the existing GPU
  operations when needed. Merge, prune, ranks, scans, weights, source-defined
  host final cuts, validation rules and numerical tolerances are unchanged.
  The existing cuda_sketch_dispatches counter includes the completed constructor
  command; input batch counts do not change. No diagnostic fields were added.

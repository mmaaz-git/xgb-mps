Authority/scope
---------------
CUDA objective/regression_obj.cu, multiclass_obj.cu, hinge.cu, quantile_obj.cu,
aft_obj.cu and HostDeviceVector/Tensor access rules define placement/behavior.
Metal branches now precede host view/device selection, using const Metal input
spans and owned device-writable gradient outputs. Prediction transforms and
regression/AFT base-margin conversions retain Metal vectors. Label validation
uses a device tensor. Checked margins compute into scratch and publish by GPU
blit only if valid. Numerical shaders and formulas unchanged.
Adaptive/AFT inputs/output binding now avoids copies for eligible disjoint
buffers, with counted host compatibility fallbacks for readonly inputs, output
aliases or insufficient alignment. GPU float2/uint2 outputs require 8-byte
alignment, although host GradientPair alignment is 4. Commands synchronous.
Adaptive small host scale-statistic collective retained exactly as CUDA's
placement; final validation flags still read as scalars. Existing byte counters
extended in scope; statistics ABI unchanged.

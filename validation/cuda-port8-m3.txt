Change and source contract:
  GatherSplitBounds selects node-major/target-minor lower and upper bounds on
  Metal. Node IDs remain host scheduling metadata. The shader copies float bits
  with uint stores; disabled constraints produce exact +/-infinity constants.
  Input shapes, target count, node ranges and output size are checked before
  dispatch. Empty gathers do not dispatch. Invalid calls preserve the last view.
  Each gather publishes a separate GPU snapshot owned by SplitWorkspace until
  its next gather or destruction. Source update/growth/destruction cannot change
  the snapshot. Old output aliases stay alive until command and borrowed-buffer
  references are released, then the new snapshot is published.
  TreeEvaluator::GatherBounds feeds actual scalar/vector EvaluateSplits and both
  InitRoot finalizers. CPU per-node bound dereferences were removed from those
  paths. Feature task assembly and finalization bind the GPU snapshot directly.
  Bound-update, clamping, scoring, tie and precision formulas are unchanged.
  CUDA authority: scalar/vector split evaluators index device bounds through
  TreeEvaluator::SplitEvaluator. Existing CUDA-source arithmetic fixtures remain
  the oracle, rather than assuming CPU tree identity for different algorithms.

Distributed Metal tree learners — Apple M3, 2026-11-04 local
==========================================================
Scope: public row-partitioned tree learners, multi-output AUC device collectives,
mixed optional-weight initialization and tracker-connected one-worker reductions.

Source authority:
- metric/auc.cu::ScaleOutputs reduces multi-output summaries on the GPU before
  normalization. Binary/ranking final scalar aggregation is separately host-side.
- objective/init_estimation.cc::FitInterceptGlmLike and regression_obj.cu
  expectile/absolute initialization select sample-mean reducers. Mixed explicit
  and implicit weights require a common denominator type across workers.
- collective/comm.h::IsDistributed distinguishes an attached tracker from the
  standalone world=-1 state; an attached tracker can still have world=1.
- tests/test_distributed/test_with_dask/test_with_dask.py documents upstream's
  unsupported distributed gblinear scope.
- python-package/xgboost/core.py::_assign_dmatrix_features skips empty matrices.
- quantile_obj.cu::InitEstimation averages per-worker quantiles, not a pooled
  global quantile; an empty worker's NaN can enter automatic initialization.

Implementation:
- MPS MultiAUC now passes a device view/DeviceSpan to GlobalSum. There is no
  summary HostSpan upload/readback between GPU generation and normalization.
- OptionalWeightedSampleMean globally selects weighted/unweighted mode. If any
  worker has explicit weights, populated workers without weights receive unit
  weights on the execution device. Empty workers enter the same reductions.
  FitInterceptGlmLike, expectile and absolute initialization use this helper.
- Metal Allreduce validates type/width and returns unchanged data for an attached
  one-worker communicator, avoiding the reduce-scatter final gather's offset 1.
- The learner-wide distributed MPS rejection is narrowed to gblinear. Public
  hist/approx/DART tree learners use the previously implemented global sketches,
  quantizers, roots, integer histograms and integer value-leaf reductions.
  The separate federated MPS rejection remains.

Reproduced findings:
- A two-worker mean probe with mixed nonempty weighted/unweighted workers gave
  3.66388893 on CPU and MPS, versus global weighted mean 2.74525309. Different
  workers had chosen integer row-count and floating-point weight denominators.
  After the shared fix both give 2.74525332 (FP32 partial-sum rounding).
  Logs: results/initialization-weight-probe-v1.log and -v2.log.
- First public learner run: attached world=1 reached an invalid ring offset.
  The identity fast path fixes it; the native runner now tests attached and
  standalone one-worker states separately.
- Empty/populated workers' serialized models differed only in feature_types.
  Recursive comparison localized that upstream Python metadata behavior. Tests
  now assert each worker's expected metadata and compare every other model
  field. Production Python behavior and numerical tolerances are unchanged.
- Early peer disconnect traces were consequences of a worker assertion failure,
  not evidence of an additional transport failure. Cleanup terminates remaining
  subprocesses on an actual failure.

Distributed Metal sketch reduction — Apple M3, 2026-11-04 local
==============================================================
Scope: ordered variable payloads and distributed feature sketches.
Distributed MPS training remains disabled.

Source authority:
- Vendored collective/allreduce_v.cuh binomial tree and callback order.
- common/quantile.cu::SketchContainer::AllReduce, including global row budget,
  prune-before-exchange, merge/prune on each edge, and final payload broadcast.
- CUDA schema synchronization and reference-cut reuse in quantile constructors.
- The source-defined host control scalars and final cut materialization remain host.

Implementation:
- AllreduceV owns shared Metal payload/scratch buffers. Local copies and reduction
  callbacks run on GPU; TCP accesses shared allocations after GPU completion.
- Host lengths are checked before resize; empty payloads and reused scratch work.
- Non-power-of-two worker counts preserve the exact source merge tree. Bounded
  sketch merge/prune is not associative, so concatenating all rows is not an oracle.
- Summaries pack column offsets and entries with source-compatible byte layout.
  Entries load through GPU copies into aligned buffers for Metal float4 access.
- Resident sketches prune with the global row-count budget, merge/prune on GPU,
  then load the broadcast summary on all workers before the existing host cuts.
- Ordinary DMatrix, MPS QuantileDMatrix and both external cache modes call this path.
  Host dense/columnar inputs, native MPS tensors, empty workers and reference cuts
  are covered. Empty schema-less workers inherit column count and feature types.
- Shared TCP Loop now keeps a failed operation's promise alive until its error is
  published. Previously EOF could wake Block() before the Result was stored,
  leading a variable reduction to invoke its callback on an incomplete header.

Focused validation and fixes:

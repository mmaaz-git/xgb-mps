Explicit adaptations/limits:
  Stable sorting ties can differ from Thrust's unspecified equal-key ordering.
  Metal's 256-entry hierarchical FP32 scan can associate differently from CUB.
    Public reference explicitly specifies that association; it is not a claim
    of NVIDIA bitwise identity. Native dyadic-weight sums do not depend on it.
  Input-summary reverse scan is serial within each column, parallel across columns.
  Rank repair applies CUDA's equations left-to-right within each column, avoiding
    CUDA's in-place neighboring-read/write race. Intended rank invariants hold;
    exact scheduling equivalence to an NVIDIA launch is not claimed.
  Raw CSR/metadata and unified group/Hessian weights still stage through host
    memory. Allocation and size-readback synchronization remain performance work.
  Adapter/device-array ingestion, adapter-built QDM bins, Apple GPU array interop
    and distributed GPU sketch exchange remain open. No new benchmark was run.

Operation scope and authority
-----------------------------
Vendored data/device_adapter.cu::CudfAdapter and
 device_adapter.cuh::EncCudfAdapterBatchImpl: independently typed columns, equal
row counts, masks, dictionaries and reference categories; data/columnar.h defines
integer/string name types. predictor/gpu_predictor.cu::DispatchedInplacePredict
uses model dictionaries when the adapter supplies categories.

Existing native proxy/ordinary/inplace C APIs now also accept a columns object.
Python MetalColumnar accepts a mapping or sequence of one-dimensional native
Metal arrays; MetalColumn adds packed uint8 validity masks and dictionary names.
Least significant validity bit comes first, 1 means valid, mask_bit is 0..7.
Numeric category names are signed/unsigned 8/16/32/64-bit integers. Strings use
int32 offsets and int8 UTF-8 bytes. Floating names and empty dictionaries reject.
Feature names/types are inferred with explicit overrides and enablement checks.
Metadata and gradient APIs remain tensor-only and reject columnar tables.

Snapshot and consolidation use GPU copies. Row values are never staged through
NumPy/CPU arrays. Existing kernels decode the mixed columns and masks, filter
missing values, construct sparse/quantile data and recode categorical codes.
The same input works with ordinary/quantile matrices, external iterators in both
cache modes, reference categories, inplace prediction and CPU tree fallback.
DLPack exports are retained across iterator resets, deduplicated by object
identity and consumed exactly once. Known producer queues synchronize before
each snapshot; generic producers/raw capsules must provide completed buffers.

Dictionary gathering copies exact bytes on GPU, including strided int64 names
that differ beyond floating precision. Outputs use guarded shared views with a
counted CPU-copy fallback. Existing host-owned dictionary containers and their
GPU sort/recode packer are reused. Host container copies/uploads and persistent
GPU dictionary ownership remain unfinished; this is not an end-to-end device
ownership claim. Consolidation currently adds a GPU copy, with optimization
deferred in accordance with the coverage-first priority.

New counters: columnar_imports, columnar_pack_bytes, columnar_gpu_time_ns,
category_import_dispatches, category_import_shared_bytes, category_import_copy_bytes.
They separate table consolidation, exact dictionary gathers and copy fallback.
Existing tensor counters retain snapshot accounting. Statistics ABI grew; all
native callers are rebuilt, including unchanged executables.

CPU defect found by equivalence tests
------------------------------------
The shared CatAccessor converted NaN to an integer before dictionary lookup.
On this ARM host that could produce code zero and turn missing rows into a real
category. Added an explicit NaN guard before the cast. Tests independently check
missing rows, not merely agreement between two paths using the same accessor.
Metal already preserved NaN. This removes undefined C++ behavior; no NVIDIA
execution or claim about measured NVIDIA NaN conversion is made.

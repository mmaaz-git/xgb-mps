Implementation:
- Explicit MPS payload views select a separate Metal backend. CPU control values
  retain CPU dispatch. Federated MPS calls remain explicitly unsupported.
- Numeric sum/min/max: F2/F4/F8, I1/I4/I8, U1/U4/U8. Numeric I2/U2/F16 rejected.
  GPU software FP64, FP16 conversion/subnormal handling, wrapping integer sums.
- Bytewise AND/OR/XOR bypass numeric type restrictions, as in CUDA. GPU-owned
  allgather buffer, then rank-ordered GPU reduction.
- Numeric reduce-scatter/allgather with owned GPU receive scratch; small arrays
  use allgather and a GPU fold. Network completion precedes GPU consumption.
- Broadcast, fixed allgather, variable ring/broadcast allgather. Variable local
  copies run on GPU; typed wrapper keeps output ownership on MPS. Overlapping
  local copies use a GPU snapshot. Empty segments skip zero-byte socket work.
- Shared allocations are CPU-addressable; actual TCP networking remains on host.
  No CPU arithmetic or resident-payload vector mirror in the new Metal paths.
- Separate collective counters avoid changing the existing Statistics ABI.

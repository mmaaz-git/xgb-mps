Operation scope and authority
-----------------------------
Vendored data/data.cu: CopyTensorInfoImpl, CopyGroupInfoImpl, CopyQidImpl,
MetaInfo::SetInfoFromCUDA. Shared predicates are in data/metainfo.h; metadata
shape extraction is defined in data/array_interface.h. These local CUDA sources
define placement, order, predicates, dtypes and shapes. No NVIDIA execution.

New XGDMatrixSetInfoFromMetal frontend supports label, weight, base_margin,
label_lower_bound, label_upper_bound, feature_weights, group and qid. Python
supports real Metal tensors plus legacy/versioned DLPack capsules, with retained
exports across single-batch quantile iterator passes. Scalars/vectors/matrices,
empty dimensions, offsets, signed/broadcast strides and supported native dtypes
retain the native tensor snapshot/lifetime/completion contract.

Float metadata: contiguous FP32 GPU blit or typed GPU conversion to FP32.
Labels reject nonfinite converted results; weights/feature weights additionally
reject negatives (including negative subnormals), while both zeros are legal.
Bounds/base margins retain CUDA's unvalidated nonfinite import behavior.
Labels/base margins preserve supplied shape instead of CPU sample-count reshape.
CUDA copies before validation; invalid float data may already have been stored.
Safe shared views permit GPU writes into the existing MetaInfo allocation; a
counted copy fallback handles destinations that cannot be safely shared. This
does not add generic private GPU ownership to HostDeviceVector/linalg metadata.

Groups: GPU integer conversion, then CUDA's host group-size prefix sum and
overflow check. Zero-sized groups remain legal. FP32/64 sizes reject; binary16
uses the source's accepted typed conversion branch. Query IDs first narrow to
uint32, then check sortedness, encode runs and cumulatively scan run counts on
GPU; final boundaries are host-owned as in CUDA. Binary64 ID conversion uses its
original bits, avoiding FP32 rounding. Unsorted IDs preserve existing groups.
Empty IDs produce [0] safely. Nonfinite/unrepresentable floating integer casts
reject explicitly; undefined C++ conversion results are not an NVIDIA parity claim.

Eight counters: metadata_copy_dispatches, metadata_convert_dispatches,
metadata_validate_dispatches, metadata_qid_dispatches, metadata_values,
metadata_shared_output_bytes, metadata_host_copy_bytes, metadata_gpu_time_ns.
Host-copy count is payload only; small status/run-count reads are not included.
CPU-only counters are zero and the new entry point rejects clearly. Every native
statistics-ABI caller must be rebuilt.

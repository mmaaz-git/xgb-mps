CUDA feature-interaction constraints on Apple M3
Date: 2026-11-04
Source base: fba35be plus the interaction change accompanying this record.

Authority and scope:
  tree/constraints.cu defines Configure, Reset, Query/QueryNode, group restoration
  and child mask propagation for both scalar and vector CUDA updaters.
  CUDA accumulates unions of groups containing split-history features; the CPU
  class only retains groups containing the entire history. With [[0,1],[1,2]],
  after splits 0 then 1, CUDA allows 2 and CPU does not. This change corrects the
  previous CPU behavior in both production MPS training and host split oracles.
  No NVIDIA execution comparison or performance benchmark was run.

Implementation:
  Host parse/CSR construction mirrors CUDA Configure. Metadata is uploaded once;
  persistent node masks have no host shadow. GPU operations zero/reset masks,
  copy retained masks on growth, union split-feature groups, propagate masks to
  parent/children, construct sampled-input masks, intersect, scan and scatter.
  Nonroot queries emit ascending unique IDs. Root and disabled queries preserve
  the supplied list; QueryNode has no root bypass and starts empty at root.
  Enabled empty groups retain split-history features; an empty parameter disables.
  Private 32-bit words permit native Metal atomics (CUDA uses 64-bit words).
  Lazy storage growth substitutes for CUDA MaxNodes preallocation; new masks are
  zero, existing masks are preserved, and children OR in parent masks.
  Scalar hist/approx and vector hist use this object; CPU evaluators retain their
  original class. Mask reset occurs once per tree. Candidate preparation still
  consumes a host feature list; commands synchronize, so full GPU ownership is
  unfinished. Monotonic-bound initialization is a separate remaining operation.
  Counters: interaction_reset/split/query_dispatches count completed commands,
  interaction_buffer_growths counts completed enlargements and interaction_gpu_time_ns
  records GPU command time. GPU error commands are counted; malformed sampled
  IDs cannot corrupt node masks. CPU-only builds expose zero counters.

  PASS 30 cases in 1.11 seconds (focused final run).
  18 strategy/method x growth x split-mode cases, 9 disabled/empty/duplicate group

  Overlap fixtures require path [0,1,2] on MPS and [0,1] on CPU. Continuation changes

  column-sampling RNG equivalence.

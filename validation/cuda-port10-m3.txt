Change and source contract:
  The GPU winner kernel resolves the selected bin to a numeric cut or negative
  infinity. Scalar splits use CUDA's exclusive-bin formula in both missing
  directions; vector forward splits use the current cut and backward splits use
  the previous cut, with negative infinity at the first bin. OHE metadata uses
  the category cut. Partition and invalid/root-only results publish quiet NaN
  without loading cut values. Existing scoring, ordering and tie rules are unchanged.
  Authority: gpu_hist/evaluate_splits.cu:129-138 and
  gpu_hist/multi_evaluate_splits.cu:269-290 in the vendored XGBoost source.
  FeatureSplitResult uses its former fourth-word padding for split_value and
  remains 112 bytes. The shader copies cut bits as integers to preserve signed
  zero and subnormal payloads. Both production evaluators consume the GPU result.
  Winner and category consumers bind the resident cut buffer directly, including
  subspan offsets. Selected-node metadata remains source-defined host control.
  No tolerance, scoring formula, public diagnostic schema or category-bit
  construction algorithm changed. Category handling is a residency regression guard.

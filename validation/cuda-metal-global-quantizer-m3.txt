Implementation:
- Split local gradient bound encoding from scale creation and row quantization.
  Preserve the single-worker combined command path. With multiple workers, GPU
  bounds complete first; four binary64 controls per target and the uint64 row
  count reduce on HOST, exactly where CUDA places these operations.
- Host global scales preserve frexp(0) and next-exponent power-of-two behavior.
  Metal stores power-of-two exponents instead of CUDA's equivalent multipliers.
  GPU row quantization then consumes those common scales. Global row metadata
  uses uint64; it does not inherit the local GPU uint32 row-index restriction.
- Explicit Context reaches both production sampling and original value-gradient
  factories. Omitting Context is supported only for single-worker low-level calls;
  distributed calls reject it instead of silently keeping local scales.
- Borrowed original gradients/layout-copy owners survive both GPU commands and
  autorelease-pool drain; transient bounds and staging scratch are released.
- Stump GPU sums reduce before weight division. Empty workers produce zero GPU
  sums and participate. Output remains Metal-owned through the production wrapper.
- Sample means reduce global row count on host; weighted means compute local
  weight sum on GPU then reduce the host scalar, including zero-weight workers.
  Each local binary64 contribution casts to FP32 BEFORE GPU output reduction,
  matching CUDA. Empty workers and zero-column inputs participate safely.
  The scalar Mean (FP32) operation remains local, as in CUDA.
- A separate global-denominator flag extends the mean kernel parameters while
  preserving its FP32-terms mode and the dedicated FP32 mean pipeline. The direct
  shader test uses the new parameter layout; its oracle/tolerances are unchanged.

GPU-owned monotonic bound state on Apple M3
Date: 2026-11-04
Source base: 2dfd24d plus the bound-state change accompanying this record.

Authority and scope:
  tree/split_evaluator.h TreeEvaluator allocates +/-FLT_MAX for 256 nodes/target,
  then grows to (2*max_child+1)*targets. CUDA HostDeviceVector::Resize selects
  device storage; DeviceUVector::resize device-copies the prefix and uses GPU
  fill for the new tail. This change ports those operations and persistent bounds.
  Feature-constraint parsing/padding remain host work, as in CUDA setup.
  No NVIDIA execution comparison or performance benchmark was run.

Implementation:
  SplitBoundsStorage owns lower/upper Metal shared buffers. Grow uses GPU blits
  and xgb_init_split_bounds exact integer stores of 0xff7fffff/0x7f7fffff, then
  publishes new views after GPU completion. No shrinking, copying or initialization
  on CPU; no host shadow. Repeated/non-growing calls leave pointers unchanged.
  Existing scalar/vector xgb_update_split_bounds writes resident buffers directly.
  Its encoder and validation are shared with the existing host-span API, which
  retains alias snapshots and borrow/staging behavior. Production bounds no longer
  require borrow/staging or host copy-back. Weight inputs still upload/snapshot.
  CPU/CUDA branches retain existing storage; MPS GetEvaluator reads completed shared
  views, reacquired after growth. Candidate preparation still reads/stages bounds.
  Unconstrained/all-zero constraints allocate and dispatch no bound operations.
  split_bounds_init_dispatches counts completed initialization/growth commands;
  split_bounds_dispatches still counts updates; timing joins split_gpu_time_ns.
  CPU-only builds expose zero counters. Native binaries require recompilation.

Native validation: tests/metal_bound_state_api.cc
  PASS 24 cases / 76 updates / 3,847,176 exact values, Metal API Validation enabled.
  Production storage: sizes 0/1/3/31/32/33/255/256/257/65537, no-growth pointer and
  counter checks, finite defaults, prefix retention, shared-view update visibility,
  alias input snapshots, malformed dimensions/aliases/extents, NaN rejection.
  Production TreeEvaluator: scalar/vector 1/2/33/129 targets, all monotonic signs,
  subnormals and signed zero, initial and repeated growth through node IDs 1023/1024;
  every bound compared with the shared CPU/CUDA formulas via CPU TreeEvaluator.
  Constraints disabled/all-zero perform no GPU initialization/update.

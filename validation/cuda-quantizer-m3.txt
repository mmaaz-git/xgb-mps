Apple M3, 2026-11-03. CUDA gradient quantizer formula alignment.
No new performance benchmark. No NVIDIA execution comparison.

Production histogram quantization now follows CUDA's quantiser.cu/quantiser.cuh:
- separate binary64 positive/negative magnitude sums for gradients and Hessians;
- max(sign sums), CreateRoundingFactor<double>(bound, n), power-of-two factor;
- integer truncation toward zero, preserving strictly positive Hessians as >= 1.
The prior maximum-times-row-count bound and ties-away rounding are removed.
Software binary64 computes bounds/scales on GPU; exact FP32 bit decoding handles
power-of-two conversion, including subnormals. Explicit nonfinite rejection and
the existing 32-bit row limit remain. Quantized gradients/scales stay on GPU.

Independent scalar CUDA-formula oracles check exact chosen scales/integer outputs.
Exact-representable sign sums compare exactly. Wide-range sign sums use an FP64
reduction error bound; CUDA and Metal reduction topologies are not claimed bitwise
identical. Boundaries include zero, powers-of-two, nextafter neighbors, subnormal
FP32 magnitudes, extreme outliers, signed cancellation, nonfinites and row limits.
19,305,306 values include 1,507,902 positive Hessians preserved at integer one.
No existing model-prediction tolerance was changed. Four additional training
checks in test_metal_cuda_quantizer.py validate the CUDA minimum-one Hessian
formula through actual hist/approx models, checking child cover and predictions.
The CPU predictions deliberately differ and that difference is asserted.
These tests ran after the 1,206-test full suite; production code is unchanged
apart from formatting. The evidence is 1,206 regression cases plus 4 new cases,
not a claimed second full-suite run.

Incomplete integration remains explicit: Metal still samples floats before
quantization; CUDA samples quantized gradients. Root/leaf statistics and histogram
cache page accumulation/subtraction still need shared integer state. This commit
does not establish full training or CUDA parity.

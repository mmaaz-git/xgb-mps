Authority/scope
---------------
CUDA common/stats.cu, common/numeric.cu, tree/fit_stump.cu and objective
initialization source define arithmetic and placement. Means, medians/quantiles,
generic reductions and stump fitting now receive explicit Metal storage;
objective initialization keeps its GPU-stage payloads on that storage.
Lower wrappers use guarded shared input/output bindings, GPU result publication,
strided byte copies and empty-result fills. Sort inputs starting at a nonzero
offset are packed with a GPU blit. Scratch results preserve input/output aliases
and no-write-on-invalid behavior. Class-histogram initial output/padding is
snapshotted on GPU. Multiclass centering reads its scalar on GPU and snapshots
an aliased scalar before writing. Existing arithmetic kernels unchanged; the new
center kernel uses the existing software-FP32 subtraction helper.
Read-only/unshareable inputs use counted uploads; gradient sum inputs need
8-byte float2 alignment although host GradientPair permits 4. Host output
compatibility uses a counted copy only when direct sharing is unavailable.
Seven native statistics fields appended and exported in JSON, zero in CPU builds.
All native clients rebuilt for the enlarged structure. Commands synchronous.

Preserved host work

and its target vector; absolute error reads target means and fitted weights.

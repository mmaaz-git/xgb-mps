Changes:
  Curve negatives: float((1.0-double(label))*double(weight)), then promote; every
  row uses this rule. Positives FP32 label*weight then promote. PR independent
  totals use sorted FP32 (1.f-label)*weight and label*weight terms, then reduce f64.
  GPU source integral shared with grouped PR. Old stabilized helper/table removed.
  Raw ROC fp/tp/area are retained for degeneracy. Binary PR nonpositive original
  totals give {0,0,0}; nonempty multi-output PR gives {1,1,NaN}. Empty outputs0.
  GPU result kernel prepares raw triples or (local_area,output_weight,integral).
  GPU NormalizeAUC implements source per-output division, weighted sum and final
  ratio. Multiclass ROC uses prevalence weights; multilabel ROC/PR use macro mean.
  Production metric MultiAUC routes MPS through preparation + existing host
  GlobalSum + GPU NormalizeAUC. CPU/CUDA algorithm paths remain unchanged.
  Intermediate triples still stage through host even locally; GPU collective
  transport/residency remains incomplete. Binary final host GlobalRatio unchanged.
  Generic metric dispatch/time counts normalization and empty metadata preparation;
  curve/sort family dispatch counts retain nonempty-curve scope. No stats ABI change.
  Optional internal AUCTrace exposes GPU terms/prefixes/totals to native tests;
  production callers pass no trace. Internal PRAUC signature changed, so ALL native
  tests were rebuilt for final validation. Public Python/C API signatures unchanged.

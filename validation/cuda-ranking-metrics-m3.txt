Changes:
  Precision: each term double(label)/double(n)*double(query_weight), followed by
  reduction. No FP32 product. Empty and topk-zero queries contribute score zero.
  NDCG: reduce discount*gain, then multiply by inverse and query weight. Inverse
  <=0 selects an unweighted fallback. NaN does not satisfy that predicate.
  MAP: inclusive segmented binary64 scan of actual sorted labels; reduce
  prefix/(rank+1)*label for rank<topk, then (area*weight)/min(total_relevance,topk).
  Empty/nonpositive-relevance fallback is unweighted. Positive relevance at
  topk zero gives 0/0. Weight denominator includes every query in all three metrics.
  Reuse recursive GPU segmented pair scan, sorted-label initialization kernel,
  query scoring and final aggregation within one command. Final totals only
  return to host. Existing metric counters retained; no statistics ABI change.
  Previous CPU-ordered serial soft-label path and integer hit path removed.
  CPU and CUDA source files unchanged.

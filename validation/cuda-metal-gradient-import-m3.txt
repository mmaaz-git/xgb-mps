Operation scope and authority
-----------------------------
Vendored c_api/c_api_utils.h::CustomGradHessOp and
c_api/c_api.cu::CopyGradientFromCudaArrays define independent typed FP32 casts
and gradient/Hessian pair packing. There is no numeric validation or negative
Hessian clamp at this import stage. The regular and split/value training entry
points define shape checks and independent pair placement. CPU casts and
host-input training are local oracles; no NVIDIA execution was performed.

Existing XGBoosterTrainOneIter and XGBoosterTrainOneIterWithSplitGrad recognize
explicit device_type tags before constructing any host ArrayInterface. Native
Metal descriptors require device_type=8 and device_id=0, actual MTLBuffers on
the active device, valid dtype/extent/offset/strides and matching G/H shape.
Both pairs are imported separately; one pair may be host and the other Metal.
A host/Metal mixture within one pair is rejected. CPU/CUDA interfaces retain
existing dispatch. CPU-only builds reject native descriptors before buffer use.

Native GPU snapshots are taken before destination reshape, then one GPU kernel
independently decodes both input tensors and packs FP32 GradientPair values.
Safe shared destination views avoid an output payload copy where eligible; the
counted fallback copies a completed GPU result. Generic gradient allocation is
still host-owned, not a private Metal HostDeviceVector/linalg implementation.

Python recognizes DLPack providers/capsules through direct Booster.boost, plain
objectives, Objective and TreeObjective (including no separate split gradients).
Managed exports stay alive through the C call; an aliased capsule across two or
four inputs is consumed once. Known producers complete their work before import;
generic providers must supply ready buffers. Legacy flattened vectors/columns
retain the upstream warning and reshape descriptors without CPU payload access.
Row vectors are not flattened. Native scalars additionally work for one row,
where the original NumPy helper expects at least one dimension. Empty shapes are
preserved. Custom callback predictions still arrive as NumPy arrays.

Counters: gradient_import_dispatches, gradient_import_pairs,
gradient_import_shared_output_bytes, gradient_import_host_copy_bytes,
gradient_import_gpu_time_ns. Input snapshots use existing tensor counters.
All native executables must be rebuilt for the extended statistics structure.

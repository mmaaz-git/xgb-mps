Production changes:
- Multi-output hist training gathers authoritative integer histogram buffers and
  each target's original quantizer scale. Exact parent and selected child sums
  persist by node ID across loss-guide queues and cache/workspace reuse.
- CUDA inclusive numeric forward/backward scans; one-hot missing-right pass then
  missing-left pass; stable projected categorical ordering and prefix/suffix
  partitions, with max_cat_threshold-1 candidates per direction.
- Binary64 argmax within each 32-bin chunk, then FP32 strict updates between
  chunks. Feature ties choose lower feature ID. Parent gain is recomputed using
  current bounds and subtracted in binary64 only after choosing the raw winner.
- Constrained per-target float weights/squares and pooled float regularization;
  bounds apply even when one target has zero Hessian and the average is valid.
- Bit-based max-delta/alpha predicates preserve subnormal parameters.
- New cuda_integer_multi_split_dispatches counter identifies the production
  path and is zero in CPU builds. Statistics ABI changed; all native API test
  executables rebuilt before use.
- Original value-gradient quantizers and float sampling replay remain separate
  from split-gradient integer sampling; reduced leaf fitting uses its own sums.

Direct native oracle: tests/metal_cuda_multi_split.mm and
  tests/cuda_multi_split_reference.h. Compiled with -ffp-contract=off and run
  against the production Metal shader with MTL_DEBUG_LAYER=1.
  PASS 1528 tasks / 76102 exact child pairs.
  Targets 1,2,3,17,33,65,129; bins 0..131 including partial/multiple warps.
  Exact gains, selected bins/directions, partition size/category order, integer
  children, binary64 views and guards. Missing/zero Hessians, monotone bounds,
  clipping/penalties, per-target scales, cancellation and subnormal cases.
  A dedicated fixture selects bin 1: global double selection would choose bin33,

Scope and source authority
--------------------------
updater_gpu_hist.cuh::Reset constructs original VALUE quantizers before replaying
float sampling. gpu_hist/leaf_sum.cu converts those sampled floats using original
scales, reduces integer pairs, adds external pages in integers, and materializes
final sums for LeafWeight. MPS now follows this order, including preparing value
gradients before tree growth. CPU preparation retains its previous post-growth
order and CPU algorithm.

A scale-only GradientQuantizer factory shares the GPU original-bound builder with
QuantizedGradients without allocating an integer value-gradient matrix. Leaf state
retains those scales, an integer sum cache, and a binary64 materialized view.
The view never feeds subsequent integer page addition. Conversion reuses the
checked binary64-to-int64 helper and preserves minimum-one positive Hessians.
Nonfinite/out-of-range sampled conversions raise an error: CUDA C++ conversion is
undefined for those values. Source metadata/command orchestration and final host
tree updates remain host operations. The legacy low-level no-quantizer leaf API
retains binary64 regression coverage; production supplies the original quantizer.

No NVIDIA hardware comparison was performed. These are CUDA-source and host-formula
checks, not measured CUDA execution equivalence. Original bound-reduction topology,
other CUDA algorithm differences and the wider coverage ledger remain outstanding.
No performance benchmarks were run. No numerical tolerance was widened.

## Producer → storage → consumer checks

Native ordinary import dispatches row count/prefix/scatter and blits entries into MPS HDV. `CudaSketchOnDMatrix` binds those entries, then `CompressedPage::PushCSR` bins/packs them directly. Tests check entry authority and zero entry readback through hist/approx regeneration before CPU comparisons. Host row offsets are the CUDA-defined sizing/window exception. Native custom-gradient import snapshots aliases before resize and produces MPS HDV pairs even for a CPU learner. Metadata setters similarly snapshot before modifying aliased labels, weights or margins.

Category dictionaries own typed Metal name storage. `CatContainer::Sort`, recoding and dictionary clone/copy preserve GPU storage and sorted-index lifetimes; adapter/predictor recoding consumes MPS mappings. Explicit `HostView`/serialization publishes a host mirror. Category state tests measure both authority and payload copies, rather than only kernel counts.

Adapter quantile construction keeps prepared entries, row pointers, compressed bins and sparse partial-row cursors on GPU through both passes. In-memory and host/disk external cache paths invoke the same compressed producers. Regeneration code joins old prefetches before replacing caches; immutable Metal buffer owners survive retained views and matrix deletion. Fixed reference-cut access does not force CPU bin materialization.

Fixed allreduce uses GPU arithmetic over owned shared Metal allocations, after synchronous TCP receive. Broadcast/allgather transport is a platform adaptation; it does not move reduction arithmetic to CPU. Variable sketch exchange retains binomial-tree callback order, GPU payload copies and GPU merge/prune. Federated fixed reduction is server arithmetic upstream as well; Metal shares the same RPC backend sequence owner. Federated variable fallback preserves ascending-rank merge order and executes each summary callback on GPU.

## Host boundaries and adaptations

Final cut queries/category validation are host work in CUDA `quantile.cu:681` and Metal `MakeCudaCuts`. CUDA `gradient_index.cu` explicitly visits ELLPACK on host to construct CPU GHist data; Metal materialization retains compressed GPU ownership while publishing CPU mirrors. Group-size prefix, host file serialization, iterator/schema orchestration, scalar size readbacks and cache mapping are also source-defined host work.

MTLBuffer shared/private allocation, guarded synchronous borrowing, command completion, TCP shared-buffer transport, and compute Snappy fallback replace NVIDIA runtime mechanisms. They are not used as excuses for missing GPU arithmetic. Snappy compression-length `thrust::reduce` only computes a debug logging ratio in CUDA; production metadata already publishes per-chunk lengths. Metal codec payload generation/decode remains GPU, with host framing/descriptor control for its port-specific block layout.

## Numerical and evidence boundaries

Sketch weighted prefix association, stable tie ordering, reverse duplicate scan association and rank repair retain explicit numerical boundaries. CUDA `FixError` reads/writes neighboring entries concurrently; Metal executes the equations left-to-right within each column. Tests in `metal_cuda_sketch_api.cc` compare exact summary fields against `cuda_sketch_reference.h`; public Python reference specifies Metal scan association. These establish local policy checks, not NVIDIA scheduling identity. The numerical reviewer owns their contract disposition.

The native tests include authority/readback/copy checks, alias reuse, retained cache readers, scalar/vector/categorical matrices, and distributed topology witnesses. Torch and MLX tests are optional-dependency-sensitive. Federated validation requires the optional build. Existing M3/local-worker evidence does not establish cross-machine transport behavior or other Apple hardware.
